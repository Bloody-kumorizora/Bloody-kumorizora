### 🎮 Обо мне

Делаю игры — от визуальных систем вроде GDevelop до Roblox и Unity.
Люблю два разных настроения:

- 🛋️ **Уютное** — менеджмент, idle, спокойные симуляторы
- 🌒 **Тревожное** — психологический хоррор, детективы, мрачная атмосфера
